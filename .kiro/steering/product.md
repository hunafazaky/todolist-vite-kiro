# Product

This is a learning project based on the Dicoding platform curriculum. It serves as a hands-on workspace for completing Dicoding course assignments, submissions, and exercises.

## Purpose

- Work through structured learning modules from Dicoding (dicoding.com)
- Build and submit projects that meet Dicoding's grading criteria
- Practice and reinforce concepts covered in each course

## Notes

- Each course or submission may live in its own subdirectory
- Code quality and feature completeness should align with Dicoding's rubric requirements
