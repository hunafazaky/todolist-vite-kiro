## Expected Stack (typical Dicoding curriculum)

Dicoding courses commonly use the following technologies depending on the learning path:

| Path | Common Stack |
|---|---|
| Front-End Web | HTML, CSS, JavaScript, Webpack, npm |
| Back-End (Node.js) | Node.js, Express, npm/yarn |
| Android | Kotlin, Gradle, Android SDK |
| React / Vue | React or Vue, Vite or Webpack, npm |

## Common Commands

Update this section once a `package.json`, `build.gradle`, or equivalent config is present.

```bash
# Install dependencies (Node.js projects)
npm install

# Run development server
npm run dev
# or
npm start

# Build for production
npm run build

# Run tests
npm test
```

## Notes

- Pin dependency versions in `package.json` to match Dicoding submission requirements
